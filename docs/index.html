So funktioniert PR-Hunter

Der automatische Scout liest ausschließlich von dir konfigurierte, öffentlich zugängliche und zur automatischen Nutzung freigegebene RSS/Atom-Feeds. Ohne Quellen ist die Liste anfangs leer.

Hier kannst du Angebote sammeln und deinen eigenen Fortschritt verfolgen. Es werden keine Instagram-DMs, Bewerbungen oder Kontaktanfragen automatisch versendet. Der Button „Text kopieren“ erstellt nur einen persönlichen Entwurf.

Deine Merkliste und dein Status bleiben lokal in Safari. Im öffentlichen Repository dürfen keine privaten Daten gespeichert werden.
